# Static Subtitle Positioning with Scoped Controls Avoidance Decoupling

Upstream Read Frog configures dynamic player controls avoidance for YouTube (`controls.checkVisibility` and `controls.measureHeight`), pushing subtitles upward whenever the playback control bar (`.ytp-chrome-bottom`) appears. In study and note-taking workflows with frequent pauses or mouse movements, this causes subtitles to repeatedly bounce vertically. While subtitle overlays require `StaticPositioning` to eliminate visual jitter, the settings panel (`PanelShell`) benefits from dynamic `ControlsAvoidance` to avoid colliding with player controls when opened. Rather than disabling controls globally at the platform level or mutating upstream drag logic, the custom fork uses a scoped provider (`StaticSubtitleOverlayProvider`) wrapping only `SubtitlesView` in `subtitles-container.tsx`. This isolates static positioning to subtitles, retains full dynamic avoidance for the settings drawer, and keeps upstream platform and drag files 100% untouched for conflict-free upstream merges.
